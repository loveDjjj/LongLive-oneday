# VBench Standard 5% augmented prompts

This directory contains 43 Qwen2.5 seed-42 generation prompts aligned one to
one with `../../vbench_standard/5pct/prompts.txt`.

- Generation uses `prompts.txt`.
- Output naming uses `../../vbench_standard/5pct/prompts.txt`.
- Evaluation uses `../../vbench_standard/5pct/full_info.json`.

The subset covers all 16 VBench dimensions. It is intended for fast regression
and comparison rather than full VBench reporting.
