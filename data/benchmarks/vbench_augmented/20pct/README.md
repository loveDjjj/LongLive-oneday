# VBench Standard 20% augmented prompts

This directory contains 186 Qwen2.5 seed-42 generation prompts aligned one to
one with `../../vbench_standard/20pct/prompts.txt`.

- Generation uses `prompts.txt`.
- Output naming uses `../../vbench_standard/20pct/prompts.txt`.
- Evaluation uses `../../vbench_standard/20pct/full_info.json`.

This is a public augmentation proxy, not a proven reproduction of the
unpublished LongLive-2.0 prompt augmentation.
